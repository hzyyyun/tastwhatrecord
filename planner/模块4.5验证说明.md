# 模块 4.5 验证说明

## 1. 验证 Chatbox 简报

1. 刷新页面。
2. 点“一键调出简报”。
3. 选择 A/B/C 中一个指令。
4. 点“生成所选简报”。
5. 检查第一段是否为：

`你现在是我的大学生活规划助理。你只负责基于以下简报帮我分析和建议，不要复读原文。`

6. 检查是否包含“【当前状态】”和“【指令请求】”。
7. 点“复制简报”，粘贴到空白 Chatbox 对话。

## 1.1 验证主线和中文状态

1. 点“主线管理”。
2. 新建一条主线，填写名称和 1-10 的战略权重。
3. 使用上移、下移和改名修改主线。
4. 删除有任务的主线时，选择转移任务或一并删除。
5. 打开任务详情，确认状态显示为待办、进行中、受阻、已完成、归档。
6. 确认“复活条件”和“验收标准”都可以使用中文填写。

## 2. 验证 Zod 写入校验

1. 在“今日”或“主线树”中点击一个任务。
2. 把“截止时间”临时改成 `明天`。
3. 点“保存任务”。
4. 应出现“数据写入被拒绝”的提示。
5. 关闭弹窗并重新打开该任务，原截止时间不应被覆盖。

Zod 会检查日期、必填字段、主线编号、优先级、任务类型、课表节次和时间格式。

## 3. 验证数据健康度检查

1. 打开“AI 与搜索设置”。
2. 点“数据健康度检查”。
3. 检查 config、goals、tasks、sources、decisions、schedule 的状态。
4. 正常情况下全为“正常”。

## 4. 验证自动快照

第一版只做“导入备份”。每次执行“一键备份”时，App 会在 IndexedDB 中保留一份自动快照，并在工具栏下显示快照时间。自动回滚功能留到第二版。

1. 点“一键备份”。
2. 检查工具栏下方的“自动快照”时间是否更新。
3. 当前恢复数据使用“导入备份”，选择 ZIP 后确认恢复。

## 5. 验证课表

1. 点“课表管理”。
2. 手工填写星期、节次、课程名和地点。
3. 点“保存课程”。
4. 返回“今日”，如果今天是该课程对应的星期，应看到课程。

修改课程：

1. 在“今日课程”或“课表管理”中点击课程。
2. 修改节次、地点或时间。
3. 点“保存课程”。

## 6. 从文本生成课表提案

1. 点“收件箱”。
2. 在“直接粘贴课表或文字”中粘贴课表。
3. 点“加入文本”。
4. 在新出现的条目中点“生成课表提案”。
5. 检查 AI 返回的课程结构。
6. 勾选确认后才写入课表。

## 7. 从图片识别课表

1. 点“课表管理”。
2. 点“从图片识别课表”。
3. 选择课表截图。
4. 检查 AI 返回的课程结构。
5. 逐项确认后才写入课表。

图片识别需要当前配置的模型支持视觉输入。

## 8. 验证课表隔离

课表使用独立的 IndexedDB `schedule` 对象存储，不写入 `tasks.json`。课表结构异常时只会被拒绝写入或出现在健康检查报告中，不会导致任务树无法加载。

## 9. Zod 拦截模拟测试

双击：

`D:\studentwork\planner\run-validation-simulation.bat`

浏览器会打开自动验证页，尝试：

1. 写入日期为“明天”的错误任务。
2. 写入结束节次早于开始节次的错误课表。

结果应显示两次“拦截成功”。错误记录不会写入 IndexedDB。
