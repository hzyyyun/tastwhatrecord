# Student Planner OS 新手部署与打包手册

```mermaid
flowchart LR
  A[本地代码] --> B[创建 GitHub 仓库]
  B --> C[GitHub Actions 发布 Pages]
  C --> D[手机打开 PWA]
  D --> E[PWABuilder 生成 APK]
  E --> F[GitHub Release 分发]
  F --> G[Redmi K90 安装]
```

## 一、部署到 GitHub Pages

### 1. 创建仓库

1. 登录 GitHub。
2. 点右上角“+” →“New repository”。
3. 仓库名建议：`student-planner-os`。
4. 选择 Public。
5. 不要勾选自动创建 README。
6. 点 Create repository。

### 2. 上传本项目

需要在电脑上安装 Git。随后在项目目录 `D:\studentwork` 打开终端，依次执行 GitHub 页面提示的命令。

重点：不要提交以下内容：

- `planner/data/`
- `planner/generated/`
- `analysis/`
- `.env`
- API Key 文件

项目中的 `.gitignore` 已自动排除这些内容。

### 3. 打开 Pages

1. 打开仓库 Settings。
2. 左侧选择 Pages。
3. Source 选择 GitHub Actions。
4. 回到 Actions，确认 “Deploy Student Planner OS” 已成功。
5. Pages 页面会显示网址，格式类似：

`https://你的用户名.github.io/student-planner-os/web/`

根地址：

`https://你的用户名.github.io/student-planner-os/`

会自动跳转到 `/web/`。

## 二、手机上安装 PWA

以 Redmi K90 为例：

1. 用 Chrome 或 Edge 打开 GitHub Pages 网址。
2. 点浏览器右上角菜单。
3. 选择“添加到主屏幕”或“安装应用”。
4. 确认名称 Student Planner OS。
5. 桌面会出现 App 图标。

## 三、PWABuilder 打包安卓 APK

### 1. 生成 PWA

1. 先确认 GitHub Pages 地址可以打开。
2. 打开 `https://www.pwabuilder.com/`。
3. 输入 GitHub Pages 的 `/web/` 地址。
4. 点 Start。
5. 检查 Manifest 和 Service Worker 状态。
6. 选择 Package for stores。
7. 选择 Android。

### 2. 建议填写

- App name：Student Planner OS
- Short name：Planner OS
- Package ID：`com.你的名字.studentplanner`
- Version：`1.0.0`
- Signing key：选择 Create new。

### 3. 下载

下载 Android 包后，你会得到：

- `.apk`：安装测试用。
- `.aab`：以后上 Google Play 用。
- signing key 文件：必须单独保存，不要上传到公开仓库。

## 四、在 Redmi K90 安装 APK

1. 把 APK 下载到手机。
2. 点击 APK。
3. HyperOS 会提示“不允许安装未知应用”。
4. 点“设置”。
5. 允许当前浏览器或文件管理器安装未知应用。
6. 返回并点“安装”。
7. 如果提示安全扫描，选择继续安装。
8. 安装后打开 Student Planner OS。

## 五、用 GitHub Releases 分发 APK

1. 打开 GitHub 仓库。
2. 点 Releases → Draft a new release。
3. Tag 填写 `v1.0.0`。
4. Title 填写 `Student Planner OS v1.0.0`。
5. 上传 APK。
6. 不要上传 signing key、API Key 或私人数据。
7. 点击 Publish release。
8. 手机打开 Release 页面，下载 APK 后安装。

## 六、数据与密钥安全

- API Key 只保存在浏览器本地加密保险箱。
- 本地加密口令不会进入备份包。
- 备份 ZIP 不包含 Key 或口令。
- GitHub 仓库不应包含 `planner/data/`。
- GitHub Actions 发布前会主动删除 `planner/data/` 和 `planner/generated/`。

## 七、断网和 API 异常

- 断网、AI 超时或 Tavily 报错时，页面顶部显示“操作未完成”，不会白屏。
- 错误提示会自动隐藏类似 API Key 的文本。
- AI 和 Tavily 失败时不会写入数据。
- 所有真实写入仍然经过 Zod 校验和人工确认。

## 八、每次更新版本

1. 修改代码。
2. 运行 `npm test`。
3. 推送到 GitHub 的 `main` 分支。
4. GitHub Actions 自动更新 Pages。
5. 如需重新打包 APK，用 PWABuilder 再次打包。
6. 在 GitHub Release 中上传新 APK。
