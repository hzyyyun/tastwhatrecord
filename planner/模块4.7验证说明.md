# 模块 4.7 验证说明

## 1. 主线 ID 和主线树

1. 打开“主线管理”。
2. 默认 ID 前缀为 `Q`。现有示例为 Q0-Q5 时，新建后应得到 `Q6`。
3. 把前缀改成 `G`，新建后应按已有 G 编号的下一号生成，例如 `G1`、`G2`。
4. 测试改名、上移、下移和修改战略权重。
5. 删除有任务的主线，检查“转移任务”和“一并删除”两个选项。

## 2. 一键调出简报 A/B/C/D

1. 点“一键调出简报”。
2. A、B、C 使用固定指令。
3. 选择 D 后，在自定义输入框中填写指令。
4. 点“生成所选简报”。
5. 检查三段结构：
   - 身份设定
   - 当前状态
   - 指令请求
6. 点“复制简报”，粘贴到 Chatbox。

## 3. 体检报告

1. 点“体检报告”。
2. 体检报告现在只检查“课表时间硬冲突”。
3. 在“课表管理”中录入两门同一天且节次重叠的课程。
4. 重新打开体检报告，应出现红灯卡片。
5. 并行任务不会被判定为冲突。

“临近截止但没有排期”的任务已经移到雷达区中的“警告 / 红灯区”，不放在体检报告里。

## 4. 收件箱处理窗口

1. 打开“收件箱”，加入 PDF、图片、Markdown、TXT、JSON 或粘贴文本。
2. 点击一条资料右侧的“处理”。
3. 选择处理类型：
   - 任务
   - 课表
   - 研究需求
   - 决策
4. 任务和决策可以选择关联主线。
5. 点“生成变更提案”：
   - 已配置 AI 时，走真实 AI 提取。
   - 未配置 AI 时，点“模拟处理”走规则模拟。
6. 提取结果只会进入变更提案，必须人工确认后才写入。

## 5. 独立研究流程

1. 点“研究任务”。
2. 直接输入研究问题。
3. 关联任务和关联主线都可以留空。
4. 选择确认后的写入方式：
   - 只保存研究记录
   - 创建或关联研究任务
   - 创建决策记录
5. 点“确认并调用 Tavily”。
6. 检查每条来源是否包含 URL、访问时间和下次复核日期。
7. 点“生成研究提案”，确认后写入。

没有 Tavily Key 时，点“模拟研究结果”可以验证完整流程。

## 6. Tavily 额度

研究界面应显示：

- 总配额：1000 次/月
- 今日已用次数
- 本月已用次数
- 剩余次数

剩余次数低于 50 时显示：

`免费额度即将用尽，超出后将按次计费。`

系统不再使用每日 10 次硬性拦截。

## 7. 无 API 验收标准

可以立即验证的纯规则功能：

- 主线管理
- 中文本地化
- A/B/C/D 简报
- 体检报告
- 收件箱处理和类型分拣
- 手工课表
- Zod 写入校验
- 自动快照字段
- 模拟处理
- 模拟研究结果
- 模拟 Chatbox 变更提案

必须接入 API 后才能验证真实效果：

- AI 文本任务提取
- AI 图片课表识别
- Chatbox 内容转结构化变更
- Tavily 真实联网搜索
- AI 变更提案质量

模拟测试入口：

- 收件箱：“模拟处理”
- 研究任务：“模拟研究结果”
- Chatbox：“模拟变更提案”
- AI 变更提案：“模拟 AI 提案”
- 课表管理：“模拟图片识别结果”
- Zod 校验：[run-validation-simulation.bat](D:/studentwork/planner/run-validation-simulation.bat)
