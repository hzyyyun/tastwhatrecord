# 模块 3 验证说明

## 1. 启动

双击：

`D:\studentwork\planner\start-planner.bat`

启动成功后会自动打开默认浏览器：

`http://localhost:4173/web/`

根地址：

`http://localhost:4173/`

会自动跳转到 `/web/`。

## 2. 配置 AI 与 Tavily

1. 点“AI 与搜索设置”。
2. 手动填写：
   - OpenAI 兼容 `baseURL`
   - 模型名称
   - AI API Key
   - Tavily API Key
   - 你自己设置的本地加密口令
3. 点“加密保存并解锁”。

保存成功后，界面会立即清空 Key 和口令输入框。下次启动时，只需要输入本地口令解锁。

Key 只保存在浏览器 IndexedDB 的加密记录中，不进入 `data/*.json`、备份 ZIP、日志或代码。

## 3. 验证 AI 变更提案

1. 点“AI 变更提案”。
2. 输入分析要求，点“生成提案”。
3. 检查每条变更的原因、变更前和变更后内容。
4. 只勾选你确认的条目。
5. 点“确认应用所选变更”。

AI 不会自动修改数据；未勾选项不会写入。

## 4. 验证 Tavily

1. 点“研究任务”。
2. 选择一个任务。
3. 确认或修改研究问题。
4. 点“确认并调用 Tavily”。
5. 检查每个来源是否包含 URL、访问时间和下次复核日期。
6. 点“保存研究记录”。

每日上限为 10 次。每次调用都需要你手动点击确认。

## 5. 验证 Key 不进入备份

1. 先配置保险箱。
2. 点“一键备份”。
3. 打开导出的 ZIP，检查 `settings.json`。
4. 其中不应出现 AI Key 或 Tavily Key。

不要把真实 Key 填进聊天、代码、测试文件或截图中。
