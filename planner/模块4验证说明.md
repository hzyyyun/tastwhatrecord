# 模块 4 验证说明

## 1. 启动

双击：

`D:\studentwork\planner\start-planner.bat`

如果浏览器没有自动打开，手动访问：

`http://localhost:4173/web/`

## 2. 验证一键调出

1. 点“一键调出简报”。
2. 检查内容是否以“大学生活规划助理”系统指令开头，并包含完整的简报正文。
3. 点“复制简报”。
4. 粘贴到 Chatbox 新对话或记事本进行确认。

简报不包含完整聊天记录，也不包含任何 Key。

## 3. 验证收件箱

1. 点“收件箱”。
2. 点“选择文件”。
3. 选择 PDF、图片、Markdown、TXT 或 JSON。
4. 检查文件是否出现在收件箱列表。
5. 点“打开原件”，确认附件可打开。

以后执行“一键备份”时，收件箱附件会包含在 ZIP 中。

## 4. 验证任务交互

1. 在“今日”或“主线树”中点击任意任务。
2. 修改状态、优先级、截止时间或验收标准。
3. 点“保存任务”。
4. 检查页面数据和任务树是否同步更新。

## 5. 验证雷达区和抬升日历

1. 点“雷达区”，页面滚动到未来 90 天雷达。
2. 点“抬升日历”，检查按抬升日期排序的任务。
3. 点击任务，确认可以修改状态。

## 6. 验证 Chatbox ZIP 或 JSON

1. 点“导入 Chatbox 对话”。
2. 选择 Chatbox 导出的 ZIP 或单个会话 JSON。
3. ZIP 文件需要再选择其中一个会话。
4. 点“提取并预览”。
5. 点“生成变更提案”。
6. 检查每条变更的原因、变更前和变更后内容。
7. 只勾选你认可的操作，再点“确认应用所选变更”。

未确认的提案不会写入数据。Chatbox 原文和 ZIP 不会进入 `sources.json`。

## 7. 验证 Tavily 可选

1. 打开“AI 与搜索设置”。
2. 只填写 AI 的 baseURL、模型、AI Key 和本地口令，不填写 Tavily Key。
3. 点“加密保存并解锁”，配置应正常保存。
4. 点“研究任务”并确认调用。
5. 应提示：

`请先在设置里填入 Tavily API Key，才能使用联网功能。`

填入 Tavily Key 后，研究功能才会执行。

## 8. 复查本轮 Bug 修复

### Chatbox 弹窗

重新打开“导入 Chatbox 对话”：

1. 选择 ZIP 或 JSON。
2. 选择会话并提取。
3. 即使需求、架构内容很长，中间内容区应独立滚动。
4. 底部“提取并预览”、“生成变更提案”、“确认写入记忆文档”和“取消”按钮应始终可见。

### 简报

重新打开“一键调出简报”：

1. 检查“当前优先（Top 3）”。
2. 检查“近期节点”。
3. 检查“今日待办”。
4. 每条任务应包含完整标题、截止日期和前置天数。
5. 日期格式应为 `YYYY-MM-DD HH:mm`。
6. 不应出现 `...` 或 `…` 形式的字符串截断。

简报优先保证内容完整，不再硬性限制为 200-300 字。
