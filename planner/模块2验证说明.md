# 模块 2 新手验证

## 1. 打开 App

双击：

`D:\studentwork\planner\start-planner.bat`

浏览器会自动打开：

`http://localhost:4173/web/`

也可以直接打开：

`http://localhost:4173/`

根地址会自动跳转到 `/web/`。

如果电脑上仍有旧的 Vite 服务占用端口，顶层 `index.html` 也会把根地址跳转到 `/web/`。

server 窗口需要保持打开。关闭 server 窗口即可停止本地服务。

## 2. 验证一键调出

1. 点“一键调出简报”。
2. 确认简报里出现今日前三项、抬升雷达和习惯。
3. 点“复制简报”。
4. 在 Chatbox 新会话中粘贴。

## 3. 验证备份与恢复

1. 点“一键备份”。
2. 浏览器会下载 `student-planner-backup-*.zip`。
3. 点“清空本地数据”，输入“清空”确认。
4. 点“导入备份”，选择刚才下载的 ZIP。
5. 分别选择“使用备份”或“保留本地”。
6. 点“确认恢复”。

也可以直接导入测试文件：

`D:\studentwork\planner\generated\module2-test-backup.zip`

该测试包不含 API Key。

## 4. 验证 Chatbox 临时提取

1. 点“导入 Chatbox 对话”。
2. 选择 Chatbox 备份 ZIP。
3. 在会话列表中只选择一个会话。
4. 点“提取并预览”。
5. 人工检查或修改需求、架构文本。
6. 点“确认写入记忆文档”。

处理完成后，ZIP 和完整聊天原文不会保存，也不会进入 `sources.json`。

## 5. 当前模块边界

- 已实现：IndexedDB、本地备份、导入恢复、冲突选择、只读简报、Chatbox 单会话临时提取。
- 尚未实现：AI 对话、Tavily 联网、PWA 离线安装、GitHub Pages 发布。
- 当前 AI Key 功能不在模块 2 中，代码和备份包中没有任何 Key。
